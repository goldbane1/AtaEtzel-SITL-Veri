# Örnek Veri (veri/ornek/)

Bu klasör, veri **şemasını** göstermek için çok küçük örnek dosyalar içindir ve
`.gitignore` istisnası sayesinde git'e **girer** (repodaki tek izinli veri yeri).

- Buraya yalnızca **çok küçük** örnekler koyun (ör. birkaç saniyelik bir uçuşın
  kırpılmış `paketler.parquet`'i + `meta.json` + örnek `ground_truth.json`).
- Büyük/tam uçuşları buraya **koymayın**; onlar `veri/ucuslar/` altında kalır ve
  git'e girmez.
- Gerçek örnek, ekibin makinesinde SITL çalıştıktan sonra üretilip buraya eklenir.

Şemanın tamamı: [../../belgeler/VERI_SEMASI.md](../../belgeler/VERI_SEMASI.md).
